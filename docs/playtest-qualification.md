## Primary shipped gameplay promise and acquisition

The source implements naturally generated, charge-bearing **dimensional fonts** at small altars. A player activates a font with an empty hand to enter a run in its configured canonical destination; a return seal or run return brings participants back, and shared runs should persist until the final participant returns (`content/ObeliskBlock.kt`, `runtime/run/RunRegistry.kt`, `gametest/ObeliskSmokeGameTests.kt`). This is the gameplay promise to qualify, not a roadmap for new dimensions or machines. `ObeliskBlockEntity.kt` handles reservoir/charge behavior; `data/ObeliskDataManager.kt` and `src/main/resources/defaults/fonts/*.json` provide definitions. A registered font item/block is `better_dimension_fonts:dimensional_font` (`registry/ModBlocks.kt`, `registry/ModItems.kt`); `return_seal`, `font_pourer`, and three collars are registered items, not evidence of crafting recipes. **No recipe JSON exists under this mod's `src/main/resources/data`**; do not invent a craftable acquisition path. The font block loot table at `data/better_dimension_fonts/loot_tables/blocks/dimensional_font.json` drops the font item (subject to block/tool behavior).

World acquisition: `data/better_dimension_fonts/worldgen/structure_set/dimensional_fonts.json` defines random-spread placement (spacing 30, separation 9, frequency 1/3); the structure and biome tag are at `worldgen/structure/dimensional_font.json` and `tags/worldgen/biome/has_structure/dimensional_font.json`. `worldgen/structure/DimensionalFontStructure.kt` rejects wet/steep surfaces and chooses an enabled definition; `worldgen/village/VillageShrinePools.kt` adds occasional font-shrine pool attempts to five vanilla village styles. `trade/DimensionalFontMapTrades.kt` exposes an authored-seller map API which uses the persisted discovery index and seller-provided currency; its vanilla wandering-trader listing is intentionally a no-op, with the pack's themed spirit traders owning that surface. No promise that a specific seed or chunk contains an accessible font follows from placement configuration alone. Pack-specific recipe roots, seller availability, and item acquisition must be checked in the **full pack** against the exact candidate, not inferred from this mod alone. Debug spawn (`commands/ObeliskCommands.kt`) is a diagnostic, not survival acquisition.
